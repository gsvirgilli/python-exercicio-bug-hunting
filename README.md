# The Bug Hunting

Exercício de debugging: correção de bugs em dois módulos Python — um manipulador de dados de músicas/artistas (`spotify.py`) e um localizador de palavras em texto (`word_finder.py`) — guiado por uma suíte de testes automatizados que aponta os comportamentos esperados.

## Tecnologias

- Python
- pytest

## Como rodar os testes

```bash
pip install -r dev-requirements.txt
pytest
```
